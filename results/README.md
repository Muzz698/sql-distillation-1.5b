# Evaluation results

Generated by `make eval-report` from the files in this folder. EX = execution accuracy (main metric), EM = Spider exact-set match, Valid = prediction runs without error. 95% CIs are bootstrap intervals. *vs base* is a paired McNemar test on the same questions: +questions only this model solves / -questions only the base model solves.

Cost per 1,000 queries uses each provider's paid list price (we pay $0 on free tiers); local models are $0 marginal cost. Latency for teachers includes network time.
